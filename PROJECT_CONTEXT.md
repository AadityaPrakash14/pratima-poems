# PROJECT_CONTEXT.md

# Project Overview

This project is a personal writing website for publishing poems and
stories.

## Primary Goals

-   Beautiful reading experience
-   Fast and responsive
-   Minimal, elegant UI
-   Mobile-first
-   Hosted on GitHub Pages
-   Built with React + Vite
-   Uses Supabase for likes and comments
-   No custom backend unless absolutely necessary

## Tech Stack

-   React
-   Vite
-   React Router
-   Tailwind CSS
-   Supabase
-   GitHub Pages

## Development Rules

1.  Never rewrite the entire project unless requested.
2.  Always explain architectural decisions before implementing them.
3.  Prefer reusable React components.
4.  Keep business logic in `services/`.
5.  Keep UI components focused on presentation.
6.  Keep folder structure organized and scalable.
7.  Write clean, readable, well-commented code.
8.  Build one feature at a time.
9.  Preserve existing functionality when adding features.
10. Ask before installing additional libraries.

## Folder Structure

src/ assets/ components/ pages/ layouts/ services/ hooks/ utils/ lib/
data/

## Coding Standards

-   Functional React components
-   Hooks only
-   ES Modules
-   Descriptive variable names
-   Responsive by default
-   Accessibility-conscious
-   Avoid duplicated code

## Workflow

For every task: 1. Explain the plan briefly. 2. State which files will
change. 3. Implement only the requested feature. 4. Keep commits
logically separable. 5. Suggest improvements only after finishing the
requested task.
